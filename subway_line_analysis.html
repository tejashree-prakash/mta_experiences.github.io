Subway Line Analysis


The Subway Line Analysis explores how rider experiences, delay patterns, and service perceptions differ across New York City’s subway lines. Our goal is to identify which lines offer smoother commutes, which struggle with chronic delays, and how these differences shape overall rider satisfaction.

Across multiple visualizations, we examine how frequently riders on each line report delays, how often those delays exceed 20 minutes, and how complaint patterns vary by route. The composite score table summarizes overall performance across four key service indicators, offering a system-wide ranking of line families. Together, these interactive graphics reveal both consistent system-wide trends, such as unusually high everyday delays on lines like the 7 or the severe long-delay burden on the Z train.

keep_delays <- c("Rarely", "A few times a week", "Everyday")

  filter(!is.na(frequency_of_delays)) |>
  filter(frequency_of_delays %in% keep_delays) |>
  count(subway_line, group_color, frequency_of_delays, name = "n") |>
  complete(
    subway_line = unique(subway_directory$subway_line),
    frequency_of_delays = keep_delays,
    fill = list(n = 0)
  ) |>
  group_by(subway_line) |>
  mutate(prop = n / sum(n)) |>
  ungroup() |>
  left_join(subway_directory, by = "subway_line") |>
  mutate(
    subway_line = factor(subway_line, levels = unique(subway_line)),

  )
