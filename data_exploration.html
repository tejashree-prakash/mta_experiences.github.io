Data Exploration


This section gives a quick look at how riders feel about the subway overall, what their top complaints are, and how delays affect satisfaction. It sets the stage for digging deeper into what’s driving rider experiences through our next analyses!


First, we want to understand the survey respondents by borough. Brooklyn and Manhattan had the greatest number of survey respondents, then followed by Queens.

#Location distribution 
borough_df <- rider_data_full %>% 
  count(borough)

plot_ly(
  borough_df,
  x = ~borough,
  y = ~n,
  type = "bar",
  hovertemplate = "Borough: %{x}<br>Count: %{y}<extra></extra>"
) %>%
  layout(title = "Survey Respondents by Borough",
         xaxis = list(title = "Borough"),
         yaxis = list(title = "Count"))

This is important to consider as it potentially biases the results seen in this borough analysis, but we tried to compensate for this issue using proportion-based analyses rather than straight counts.


How do riders feel about their MTA experience?

This section summarizes overall rider satisfaction across all boroughs and regions. By aggregating responses on overall satisfaction, it provides a clear snapshot of how satisfied riders are with their subway experience at a high level.

#Satisfaction 
satis_overall <- rider_data_full %>%
  count(overall_satisfaction) %>%
  mutate(prop = n / sum(n),
         percent = paste0(round(prop*100,1), "%"))

#Set colors to gradient manually 
viridis_colors <- viridis(nrow(satis_overall))

plot_ly(
  satis_overall,
  labels = ~overall_satisfaction,
  values = ~prop,
  type = "pie",
  hole = .5,
  textinfo = "label+percent",
  marker = list(colors = viridis_colors),   # ← APPLY VIRIDIS HERE
  hovertemplate = "%{label}<br>%{percent}<extra></extra>"
) %>%
  layout(title = "Aggregated Satisfaction Levels")

The data show that a majority of riders (36.6%) are not satisfied with their experience using the MTA, while an additional 24.9% are highly unsatisfied. Together, this indicates that over 60% of respondents have a negative view of the subway system. Fewer riders reported being neutral or satisfied, highlighting significant room for improvement. These patterns will be further dissected through borough analysis, subway line analysis, and regression analysis. Understanding these differences can help identify targeted areas for service enhancements and better meet the needs of riders across the city.


What are rider’s main complaints? 

#  Chart B - Summary of top complaints overall

# First, create the complaint column by splitting top_three_complaints
complaint_data_time <- complaint_data_time |>
  mutate(
    complaint = str_split(top_three_complaints, ",\\s*")
  ) |>
  tidyr::unnest(complaint)

# clean and count complaint types properly
top_complaints <- complaint_data_time |> 
  mutate(
    # Clean each complaint - remove [, ], ', and trim whitespace
    complaint = str_remove_all(complaint, "\\[|\\]|'"),
    complaint = str_trim(complaint),
    # Standardize complaint types 
    complaint = case_when(
      str_detect(tolower(complaint), "crime|safety") ~ "Crime / Safety",
      str_detect(tolower(complaint), "delay") ~ "Delays",
      str_detect(tolower(complaint), "overcrowd") ~ "Overcrowded trains",
      str_detect(tolower(complaint), "route") ~ "Frequent route changes",
      str_detect(tolower(complaint), "fare") ~ "High fares",
      str_detect(tolower(complaint), "handicap|accessibility") ~ "Lack of handicap access",
      str_detect(tolower(complaint), "old|train.*old") ~ "Old trains",
      str_detect(tolower(complaint), "station|infrastructure") ~ "Station infrastructure",
      str_detect(tolower(complaint), "service") ~ "Customer service",
      TRUE ~ complaint
    )
  ) |> 
  filter(complaint != "", !is.na(complaint)) |>  # Remove empty complaints
  count(complaint) |> 
  arrange(desc(n)) |> 
  head(10)


# Create the bar plot
bar_plot <- top_complaints |> 
  plot_ly(
    x = ~n,
    y = ~fct_reorder(complaint, n),
    type = "bar",
    orientation = "h",
    text = ~n,  
    textposition = "outside",  
    textfont = list(color = "black", size = 12),
    hoverinfo = "text",
    hovertext = ~paste("Complaint:", complaint, "<br>Count:", n),
    marker = list(color = viridis::viridis_pal()(10),
                  line = list(color = "rgba(0,0,0,0.3)", width = 1))
  ) |> 
  layout(
    title = list(text = "Top 10 Complaint Types", font = list(size = 16)),
    xaxis = list(title = "Number of Complaints", 
                 tickfont = list(size = 12)),
    yaxis = list(title = "", 
                 tickfont = list(size = 12),
                 automargin = TRUE),
    margin = list(l = 200, r = 50, t = 50, b = 50),
    showlegend = FALSE
  )

bar_plot

Above we see the most common subway complaint types across the five New York City boroughs. Delays (3932) and overcrowded trains (3078) are the most frequently reported issues overall, and less frequent concerns like old trains or crime appear at much lower levels across all boroughs. Note: Counts represent individual complaint selections rather than unique respondents. Because each participant could list up to three complaints, totals may exceed the number of respondents.

delay_reason_plot

We can quickly notice that the top delay reason is train traffic. Within the train traffic bar, we can see that 1,526/2,608 people which is about 59% reported that they were unsatistfied with the train due to train traffic. It seems that the delay reason might have an impact on the overall satisfaction, but it may just be a piece to the puzzle.
